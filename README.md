## Sobre

Explore a página dedicada ao icônico Kobe Proto 8, um dos modelos mais revolucionários do basquete. Desenvolvido com HTML e CSS, este site apresenta um design moderno e dinâmico, refletindo o estilo e a performance do lendário tênis. Descubra detalhes técnicos, imagens de alta qualidade e a história por trás deste modelo que marcou uma era. Com uma estética clean e elementos visuais inspirados no esporte, a página oferece uma experiência imersiva para os fãs de Kobe Bryant e apaixonados por sneakers.
